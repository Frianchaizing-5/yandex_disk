# yandex_disk

Проект для публикации и экспорта индекса файлов из Яндекс.Диска через API.

## YANDEX_DISK_EXPORT

Основная документация проекта находится в файле `YANDEX_DISK_EXPORT.md`.

В нем описаны:
- получение OAuth токена;
- запуск публикации папок;
- экспорт CSV с полями `catalog`, `filename`, `public_url`;
- практические примеры команд.

## Быстрый старт

1. Укажите токен в локальном окружении (не коммитьте секреты):
   - переменная `YANDEX_DISK_TOKEN`;
   - либо локальный файл `env` (уже в `.gitignore`).
2. Используйте скрипты:
   - `publish_yandex_disk_tree.py` — публикация дерева;
   - `export_yandex_disk_index.py` — экспорт индекса файлов;
   - `download_yandex_disk_folder.py` — скачивание папки.
